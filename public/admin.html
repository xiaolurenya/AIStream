站点的影片数据、播放线路、解析地址全部来自上游接口。上游地址 / 密钥 / Cookie 失效后，在这里直接换成自己申请的新值即可，保存后立即生效，无需改代码、无需重启。

仅供自用：这里的值只存在你自己的 config.json 里，不会上传到任何地方。

读取中…
① 激活本站
② 授权码台账 — 签出去的每一个码：状态 / 停用 / 改时长 / 删除
停用只拦「还没激活」的码；对方已经激活的实例是离线校验，无法远程关停，只能让对方自行解除。
「改时长」= 给同一台机器重签一个新码（签名里写死了到期时间，改不了旧码），旧码自动标记已换发。
机器码有效期状态签发时间激活时间备注操作
③ 给别人签发授权码 — 需要签发私钥，公开仓库版本没有私钥，签不了码
④ 签发私钥 — 只有站长这台机器需要配；丢了就再也签不出新码，请自行备份
⑤ 前台「怎么拿到授权码」 — 留空则用代码里内置的默认文案（server.js 的 LIC_CONTACT）
⑥ 站点地址（激活回执） — 填你自己的访问地址，会嵌进签出的授权码：对方激活成功的瞬间自动向你上报「已激活+对方机器码」，台账里激活时间/状态才会实时更新。留空则不上报。
⚠️ 联系方式与站点地址都是「签码那一刻」嵌进码里的 —— 改了之后，新签 / 换发的码带新值；已经签出去的旧码用「换发」刷新（换发同样免费、永久）。
本实例没有签发私钥，不是签发方 —— 上面的「授权码台账 / 签发授权码 / 签发私钥 / 前台联系方式」已隐藏。
这些功能只有持有私钥的签发方（站长自己那台）才有，别人拿到源码也签不出授权码。

广告联盟两种对接方式：① 自定义广告——后台配图片 + 跳转链接（最常用，立即生效）；② 联盟代码——直接粘贴广告联盟（百度联盟 / Google AdSense / 各类 CPA、CPS）提供的 <script> 或 <iframe> 片段，前台用沙箱 iframe 原样加载。各位置可单独开关；「会员去广告」在「积分会员」页按等级配置。
