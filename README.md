## ⚠️ 一、关于授权：你能用，但你签不了码

授权体系采用 **RSA-2048 非对称签发**：

| | 在哪 | 能做什么 |
|---|---|---|
| **公钥** | 随代码分发（写在 `server.js` 里的 `LIC_PUB`） | 只能**验证**一个授权码是不是真的、是不是签给这台机器的 |
| **私钥** | **只存在于签发方自己的 `data/config.json`**，绝不进仓库 | 才能**签发**授权码 |

由此得出的三条事实：

1. **你 clone 下来的这份代码没有签发能力。** 后台「授权管理 → 签发授权码」会提示
   `本实例没有签发私钥，无法生成授权码`——这不是 bug，是设计如此。
   想给别人发码，必须先从签发方拿到私钥并导入到你自己的实例（后台 → 授权管理 → 导入私钥），
   且这份私钥**绝不能提交进任何公开仓库、群里或聊天记录**。
2. **授权码一机一码、一律永久。** 码里绑定了你这台的机器码（首次启动写入 `data/config.json`），
   换机器或换掉 `data/` 目录后机器码会变，需要重新签发。
   **没有 30 / 90 / 180 / 365 天这些档位——签发即永久，不存在到期、续费、订阅。**
3. **别改代码绕开门禁。** 绕过去不会给你任何额外功能，只会让你失去后续更新和排查支持；
   而且本程序的功能本来就全部开放，激活与否不影响任何能力，只影响能不能打开站点。

- 激活后**全程离线校验**：不联网也能一直用，不需要始终连着签发方的服务器。
- 签发方可以停用「还没激活」的码；**已激活的实例无法被远程关停**。

## 二、这个仓库里有什么，没有什么

分发形态是**空壳 + 授权体系**：功能全给，凭据和源地址一律不内置。

**✅ 仓库里有**

| 模块 | 说明 |
|---|---|
| 采集站聚合 | 苹果CMS v10 标准采集 API：单站接入 / 连通自检 / 批量导入 / 多站并发聚合搜索 / 按 id 精确取源 |
| 播放 | Artplayer + HLS.js（随仓库自托管）、m3u8 广告过滤、**换源面板（解析线路优先 + 跨站切换）**、断点续播、跳过片头片尾、倍速 |
| 内置数据源 | 内置热门影视数据（剧集 / 电影 / 综艺 / 动漫），**无需任何密钥**，空壳开箱即有内容 |
| 追剧日历 | 一周 7 天更新，三级回退：上游日历 → TMDB → 内置热门池；没配任何外部源也有数据 |
| 后台 | 首页栏目、采集站、解析线路、上游接入、用户与会员、权限矩阵、积分签到、邀请注册、公告广播、IPTV、广告过滤、授权管理、日志 |
| 授权体系 | RSA-2048 非对称签发，一机一码，**永久授权** |
| 安装文件 | `Dockerfile`、`docker-compose.yml`、宝塔/PM2 与裸 Node 说明 |

**❌ 仓库里没有**（这些必须由**你自己**填，别指望 clone 下来就能直接看片）

- 任何第三方采集站地址 —— 程序只提供「接入采集站」的能力，不内置任何一个站点
- 上游 API 地址 / HMAC 密钥 / Cookie
- 任何人的 IPTV 直播源
- TMDB API Token（`TMDB_TOKEN` 留空也不影响采集站与内置数据源）
- 用户数据、观看历史、收藏、日志、图片缓存
- 授权码签发用的 **RSA 私钥**

> 为什么：这些凭据一旦内置，N 个实例共刷同一份资源 → 上游限流 / 封号 / 封 IP，所有人的站一起遭殃。
> 所以这里只给能力，不给凭据。**一实例一号，禁止共用。**

## 三、功能详解

### 前台

- **首页**：栏目可混排 —— TMDB 榜单、你接入的采集站、**内置热门数据**。加了采集站会自动成为栏目，不用先去配。
- **分类浏览**：电影 / 剧集 / 动漫 / 综艺，分页加载，无外部源时自动用内置热门填充。
- **搜索**：TMDB 与所有采集站**并行**搜索，一次返回结果；带搜索历史与热词。
- **详情与播放**：海报、简介、导演演员、地区语言、类型、评分、选集、猜你喜欢。
- **追剧日历**：本周 7 天每日更新，按天切片聚合。
- **继续观看 / 收藏 / 历史**：跨设备靠同一账号，进度绑集号（换集不会串进度）。
- **公告与广播**：后台可发全站公告，支持 SSE 实时推送。
- **移动端**：独立移动端适配，播放页在手机上单独优化（选集紧跟播放器、快捷栏等）。

### 播放

- **Artplayer + hls.js 自托管**在 `public/vendor/`，页面**不请求任何外部 CDN**，内网 / 断网也能播。
- **换源面板**（点播放器下方「当前播放线路源」）：
  - 采集模式下同样可用：**解析线路**（后台配的网页解析器，默认排在最前）与**采集线路**（各站 × 各播放源，可跨站切换）。
  - 站方给的是 m3u8 直链 → 直接播；给的是播放页地址 → 自动包一层解析线路播放。
- **广告过滤**：服务端改写 m3u8 清单剔除插播段；站方切片不带 CORS 头导致浏览器拉不动时，
  可开后台「广告过滤 → **切片代理**」让切片走服务端代理（代价：占用你的上行带宽）。
- **起播看门狗**：20s 无画面软重启、40s 才换线；一旦有缓冲数据绝不误换线（避免手机上把慢起播当成失败）。
- **跳过片头 / 片尾**：自适应片尾区间；手动拖过进度条后本集不再自动跳片尾。
- 断点续播、倍速、投屏（DLNA/SSDP 需要 host 网络，见下）。

### 后台

- **首页栏目**：TMDB 榜单 / 采集站 / 内置热门 混排，可增删排序，配了立即生效。
- **采集站**：添加时**地址会自动规范化**（只填域名会自动补全成 `/api/php/provide/vod`；
  填了 m3u8 直链或播放页地址会被当场拦下并说明原因）；支持「立即自检」真打一次接口，
  以及批量导入（逐条真测后才入库）。启动时还会把历史遗留的错误地址自动修正一遍。
- **解析线路**：填网页解析器地址，供「播放页地址类」的分集使用。
- **用户 / 会员 / 权限**：多用户、会员等级、按功能分组的权限矩阵（可对单个用户单独开关），
  注册开关、注册默认权限模板、邀请注册（需邀请码）。
- **积分 / 签到**：观看与签到得积分，可作会员权益门槛。
- **IPTV**：直播源接入与分组权限控制。
- **公告 / 广播**：全站公告、连推广播。
- **广告过滤**：开关、黑名单、切片代理。
- **授权管理**：导入私钥、签发授权码、授权码台账（停用 / 恢复 / 换发 / 删除）、前台联系方式。
- **日志**：服务端 + 客户端（播放器）日志统一查看，便于排查播放问题。

## 四、三分钟装好（Docker Compose，镜像直拉）

仓库里那份 `docker-compose.yml` 就是最终形态——**粘贴即用，不需要本地构建**：

```yaml
services:
  aistream:
    image: xiaoluya/aistream:latest
    container_name: aistream
    user: "0:0"
    restart: always
    ports:
      - "8890:8890"                      # 想换端口就改左边
    environment:
      - TZ=Asia/Shanghai
      - PORT=8890
      - DATA_DIR=/data
    volumes:
      - /vol1/1000/aistream/data:/data   # 左边改成你自己的路径
```

```bash
docker compose up -d
docker compose logs -f        # 看到 [aistream] listening on 0.0.0.0:8890 就成了
```

打开 `http://你的IP:8890` → 会直接进**激活页**。

> 用的是默认 bridge 网络 + 端口映射，**不抢占宿主机网络栈**，同一台机器上跑多个实例只要换左边端口就行。
> 代价：**DLNA/SSDP 投屏靠广播包发现设备，bridge 下跨不过去**。要用投屏就把 `ports:` 换成 `network_mode: host`。

### 飞牛 fnOS

1. **应用中心 → Docker → 项目（Compose）** → 新增，把上面那段（或仓库里的 `docker-compose.yml`）整段粘进去，
   把卷路径改成你自己的（如 `/vol1/1000/aistream/data:/data`），保存并启动。
   - 路径要选一个**它下面没有其他 compose 项目的空目录**，否则飞牛会报「父级目录已存在compose项目」。
2. 防火墙放行 `8890`。要外网访问就在 fnOS「系统设置 → 安全 → 防火墙」放行，再做反代。

### 宝塔（BT）

1. 软件商店装 **Node.js 版本管理器**（选 20 或 22）+ **PM2 管理器**。
2. 把 `server.js` 和 `public/` 上传到 `/www/wwwroot/aistream/`。
3. 终端执行：

```bash
cd /www/wwwroot/aistream
export DATA_DIR=/www/wwwroot/aistream/data
export PORT=8890
pm2 start server.js --name aistream
pm2 save && pm2 startup
```

4. 网站 → 反向代理 → 目标 URL `http://127.0.0.1:8890`，或直接在防火墙放行 8890。
5. 改代码后：`pm2 restart aistream`。

### 裸 Node / 本机调试

```bash
DATA_DIR=./data PORT=8890 node server.js
```

## 六、装完第一步：接入采集站

空壳激活后首页会显示引导卡片，按它走两步：

1. **后台 → 采集站 → 添加**
   - API 地址填苹果CMS v10 采集接口，两种写法都认：
     - `https://example.com`
     - `https://example.com/api.php/provide/vod`
   - 保存时地址会自动规范化：只填域名会自动补全成 `/api.php/provide/vod`；
     填了 **m3u8 直链**或**播放页地址**会被当场拦下并说明原因——那不是采集 API。
   - 点「**立即自检**」，会真打一次接口，返回 `连通 + 拉到 N 条` 才算通过；不通会明确告诉你是地址错、超时还是返回格式不对。
2. 保存后回前台刷新 —— **不用再配栏目**，首页会自动把该采集站的最新内容作为栏目显示出来。
   （想精挑栏目内容，去后台「首页栏目」里加，支持 TMDB 榜单 + 采集站 + 内置热门混排。）

想批量导入就用后台的「**批量导入**」（每行一条地址，逐条真测后才入库）。

> **一个采集站都没配也能用**：首页会展示内置的热门影视数据（无需任何密钥），
> 只是没有播放源——播放线路仍需你自己接入采集站。

### 手机 APP（Android，连你自己的站点）

仓库里的 [`app/`](app/) 是一个官方 Android 客户端：**WebView 壳 + 自带登录页**，
不是连某个固定服务器的那种 APP——它让你填**你自己站点**的地址（IP / 域名 + 端口）和账号密码。

- **连接自己的站点**：首次打开填地址 + 端口 + 用户名 + 密码，验证通过后自动进入站点；
  账号密码只保存在手机本机。
- **横屏**：普通页面跟随手机「自动旋转」开关；**播放进全屏时自动转横屏并隐藏状态栏**（不受系统锁竖屏影响）；
  右上角 ⚙ 里还能随时手动切横 / 竖屏。
- **会话自动续期**：登录态 7 天过期被弹回登录页时，APP 会用保存的账号静默重登一次，无感继续看。
- **网页视频全屏、返回键网页后退、外链走系统浏览器**；https 站点挂 http 播放源也放行。
- **不需要自己编译**：仓库配有 GitHub Actions（`.github/workflows/android.yml`），任何对
  `app/**` 的改动推送后都会自动云构建，到仓库的 **Actions → Android APK → 最新一次运行 →
  Artifacts → AIStream-APK** 下载即可（需登录 GitHub）。
- 本地编译也一样简单：装好 Android Studio / JDK17 后在 `app/` 目录 `gradle assembleDebug`。

## 八、常见问题

**Q：装完打开是激活页，卡住了怎么办？**
找给你程序的人要授权码。自己就是签发方的：先在你自己的实例（有私钥那份）后台签一个码，
粘进激活页即可。**没有跳过激活的开关**——想先看看效果，就在你自己的实例上给自己签一张码。

**Q：首页空白 / 没有内容？**
采集站还没加。后台 → 采集站 → 添加 → 立即自检。没配采集站时首页会显示内置热门数据，不会白屏。

**Q：采集站自检不通？**
按顺序排查：① 地址要是完整 URL（不能是 m3u8 直链 / 播放页）；② 目标站是否只对特定 UA / IP 开放；
③ 容器能否出网（`docker exec aistream node -e "fetch('https://example.com').then(r=>console.log(r.status))"`）。

**Q：播放页提示「暂无分集」？**
先确认采集站自检通过。若是内置热门数据点进去，程序会自动按片名到你的采集站里检索播放源，
检索不到就是你的采集站里没有这部片——换一部，或换个采集站。

**Q：海报图不显示？**
海报走的是第三方图床直链。容器访问不了就配 `OUT_PROXY`；或者开启图片磁盘缓存（默认已开，落 `data/dimg-cache/`）。

**Q：忘了 admin 密码？**
默认账号是 `admin` / `admin123`。改密码在后台「用户」里直接改；都忘了就删 `data/users.json` 重启，会重建默认管理员。

**Q：数据在哪？升级会不会丢？**
全在 `data/`。`docker compose pull && docker compose up -d` 重建容器不会丢，只有删掉 `data/` 目录才会。
**升级前先 `cp -r data data.bak`。**

**Q：我没填上游（API 地址 / Key / Cookie），只有采集站，能正常用吗？**

**能。采集站是完整独立的一条链路，不依赖上游，也不依赖 TMDB。**

| 功能 | 只有采集站时 |
|---|---|
| 首页内容 | ✅ 加了采集站就自动成栏目；没加也有内置热门数据 |
| 搜索 | ✅ 采集站聚合搜索照常出结果 |
| **播放** | ✅ 走采集站自己的直链；站方给播放页地址时自动走解析线路 |
| 追剧日历 | ✅ 有内置热门池兜底，7 天都有数据 |
| 收藏 / 观看历史 / 用户 / 权限 / 公告 | ✅ 全都正常，不依赖任何外部源 |
| 上游专属功能（上游榜单栏目、上游线路解析、短剧） | ⚪ 空着，不报错 |

后台「上游接入」那一页留空即可，站点正常工作，不会白屏也不会报错。
想补上游就去后台填上自己的地址/密钥（一实例一号，别共用）。

**Q：机器码会变吗？**
机器码在首次启动时写入 `data/config.json`，**只要数据卷还在，重建容器都不变**。
但换了数据卷、或清空了 `data/` 目录，机器码会重新生成 → 需要重新签发授权码（重新签发同样免费、同样永久）。

> 注意：机器码里包含容器 hostname，Docker 容器的 hostname 默认是容器 ID，
> 所以**同一台机器上跑两个实例，它们的机器码是不一样的**，各自要各自的授权码。
