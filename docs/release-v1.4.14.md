# AIStream TV v1.4.14

大哥投影实拍 4 图点名：选台行下面滚动内容要像参照样式（正在播 → 接下来）；当前版本文字与台标重叠、跑马灯「…」后面的字露不全、频道乱跳；滚动还是过头盖住前面的编号方块。

- **节目单内容改成参照样式两段式**：选台行下面那行滚动内容由原来只有「▶ 正在播 xx」改为 **「正在播 xx 几点结束　接下来 xx 几点开播」**，滚完正在播接着滚接下来，和图2 参照样式两段信息一致。
- **跑马灯遮挡/重叠/露不全/乱跳一次根治（`MarqueeTextView` 自绘裁剪，核心重构）**：
  - **根因**：台标是 Coil 异步加载，成功回调把台标容器 GONE→VISIBLE 会把名字区挤宽/挤窄，而跑马灯行程只在绑定时量一次 → 行程时大时小：大了滚过头（文字左端越出壳，视觉上盖住台标甚至编号方块，图3/图4），小了末尾的字永远露不全；每次条目复用行程忽大忽小、相位重置，看起来频道在乱跳。前两版靠「外层壳 clipChildren 裁剪」在部分盒子上不可靠。
  - **新方案**：自定义 `MarqueeTextView`（继承 TextView）——View 恒为 `match_parent`（=名字区宽），**View 本身永远不越界**；onDraw 里 `clipRect(自身边界) + translate(-offset)` 自绘文字，**文字滚到哪都被裁在自己边界内，物理上不可能遮挡编号/台标**。
  - **行程永远准**：每一轮滚回开头时自动重新量宽；台标加载回调里也主动触发重测，台标异步挤压名字区立刻跟上，不再出现「按旧宽算定就错到底」。
  - **短文字绝不滚**：CCTV1 这类没超宽的台名一帧都不动。
  - 节奏不变：开头停 1.2s → 匀速滚到末尾最后一字完整可见 → 末尾停 0.8s → 回开头，行内始终有字无空窗。
- 面板顶部节目单两行同步换 `MarqueeTextView`；原「FrameLayout 裁剪壳」方案整体废弃删除。
- 版本号 1.4.14（versionCode 28）。
