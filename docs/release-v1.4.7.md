# AIStream TV v1.4.7

大哥逐图点名的 TV 端体验再打磨（基于 v1.4.6 继续修）：

- **左导航轨选中焦点框不再被裁**（图1）：`rail` 容器加 `clipToPadding="false"`（原来 padding 区内的放大描边被裁掉），并把三档 `rail_width` 各缩 6dp（134/152/172 → 128/146/164），选中任栏目焦点框左右都完整显示。
- **分类页「显示更多」连环点击不再卡**（图2）：彻底根治二次卡顿——用 `HashMap` 页缓存 + `prefetching` 去重标记，点「显示更多」先等预取落地（最多 5s）再取缓存或现拉，连环点也秒出；按钮在加载时显示「加载中…」，拉完恢复「显示更多」并立刻预取下下页。
- **所有栏目整体再上移**（图3）：分类页根 `paddingTop` 56→44dp、`paddingBottom` 24→20，网格 `layout_marginTop` 18→10dp；标题改成「品牌色竖条 + 栏目名」组合，比光秃秃一行字更有精气神。
- **IPTV 选台面板按参照样式重做**（图4/5）：左侧分组改竖列（后台 `groupOrder` 什么列表就是什么列表，**不再硬塞「全部频道」**），右侧频道列表；去掉行内分组小字和播放进度条，只留「三位编号 + 台标 + 台名（+节目小字）」；选台行高 58→62dp、行距放宽，不再拥挤。面板宽度三档再放宽（264/300/320 → 290/330/360）容纳两栏。
- **屏幕自适应 + 动画**：海报卡加 `bg_card` 圆角底 + 代码兜底 `clipToOutline`（XML 仅 API31+ 认）；分类网格进场走 `layoutAnimation`（逐批上浮淡入，只进页跑一次）；三档 dimens（手机/平板/1080p TV）继续保底自适应。
