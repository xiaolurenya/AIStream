# AIStream TV v1.4.21

大哥投影实拍打回 v1.4.20：「这就是你修复的大海报 右边清晰左边模糊这能看吗，我要的是完整的清晰的不是模糊的」。

## 修法：hero 只出一张海报
- **彻底去掉模糊层**：v1.4.20 的「背景放大磨砂 + 前景清晰」双层设计废弃——左右两种观感割裂，大哥不接受。
- `heroBg`（背景放大层）整个废弃：布局 `visibility="gone"` + 代码不再加载、预览小窗显隐不再管它。
- **hero 唯一画面 = `heroPoster`**：右侧锚定、`fitCenter` 原比例 —— 完整（人物全）、清晰（豆瓣 large 原图，v1.4.20 服务端已改）、不拉伸不模糊。
- 左侧 = 干净的深色底 + 渐变压暗（bg_scrim_left），标题/年份/立即播放照旧在左下，轮播圆点底部居中。
- v1.4.20 的服务端修改（`pic.large` 优先）保持不变 —— 这是清晰度的根。

## 效果
一张完整清晰的海报立在右侧，左边纯色渐变衬文字，和「别人的海报」一样干净利落，没有任何模糊成分。
