# AIStream TV v1.4.12

大哥投影实测三张选台面板截图点名：无台标频道左边空一大半、快速下翻顶部挡搜索框、跑马灯滚动距离不够/不流畅。

- **跑马灯彻底重做（核心，新 `MarqueeLabel` 统一调度）**：系统自带 marquee 有三个毛病——① 每个 TextView 各挂一条动画回调，选台列表一屏十几个同时滚，盒子掉帧卡顿；② 一轮滚完要把整行等空、文字再从右边爬回来，看起来「左边一大半是空的」；③ 速度/行程不可控，长台名像滚一半就重头（「滚动距离不够」）。现在全局只跑**一条帧回调**按帧时间差统一推进所有跑马灯（60fps 恒速、42dp/秒），一轮节奏 = **开头停 1.2s（读得清完整台名）→ 匀速滚到文本末尾最后一字完整可见（行程 = 真实超宽，一字不少）→ 末尾停 0.8s → 回开头**，全程行内始终有字、无空窗期；没超宽的短文字不注册不占帧。台名 / 「▶ 正在播」/ 面板顶部节目单全部换新跑马灯。
- **无台标频道文字靠左补刀**：上一版只处理了「没配台标地址」的频道；这次连**台标地址存在但加载失败**的频道（果果1 这类）也一起处理——Coil 加载失败回调里把台标容器整个 GONE，不再留一截空位。
- **快速下翻不再顶到搜索框**：频道列表与搜索框间距 12→14dp，列表顶部加 6dp 内边距并恢复顶部裁剪，快速滚动时行不会贴上/顶到搜索框。
- 版本号 1.4.12（versionCode 26）。
