# AIStream TV v1.4.15

大哥投影实拍 5 图 + 1 项优化点名，本版围绕「丝滑、统一、清晰、无阴影」做了一轮收尾打磨（8890 正式版不动，18897 测试容器验收）。

## 1. IPTV 选台行跑马灯丝滑化（图1）
- **根因（生硬/卡顿）**：① 跑马灯回程是「瞬间跳回开头」，视觉上每轮末尾「啪」一下弹回去，很生硬；② 重绘不节流，高端盒子上其实还好，低端盒子每帧都 invalidate 开销大，偶发卡顿。
- **平滑回程**：回程由瞬间跳回改为**按去程一半速度（夹在 250~500ms）匀速滚回开头**，`backMs = scrollMs*0.5 coerceIn(250,500)`，视觉连续无突跳。
- **重绘节流到 ~30fps**：新增 `FRAME_MS=32L` 累加器，相位照常计算，但只有累加 ≥32ms 且偏移真变了才 `invalidate()`，低端盒子掉帧直接救，肉眼依旧顺滑。

## 2. 所有栏目「显示更多」连点卡顿 + 边框统一（图2）
- **连点卡顿**：分类网格翻页连续点「显示更多」后会掉帧/卡。在 `noAnim(rv)` 之后补 `rv.setHasFixedSize(true)` + `rv.setItemViewCacheSize(8)`，固定尺寸 + 放大视图缓存，连点翻页不再重建测量/回收抖动。
- **边框大小统一**：末尾的「显示更多」卡原来是 `wrap_content` + `bg_chip` 小圆角短条，跟海报格宽高圆角都不一致，网格里一眼突兀。改为 **`@dimen/poster_h` 高 + `@drawable/bg_card` 底色圆角**，跟普通海报格一模一样的一格，排进网格齐整统一。

## 3. 首页左边栏目背景配色重搭 + 文字清晰（图3）
- **配色压暗一档**：四张侧栏渐变全部压暗，让白字在深色底上更立得住：
  - `bg_side_home`：`#3F73B0/#2A568A` → `#33598C/#24466F`
  - `bg_side_fav`：`#A98CF2/#7C66E6` → `#6A57D4/#5346B8`
  - `bg_side_live`：`#69B5F2/#3E92DF` → `#3B8BD4/#2A6FB4`
  - `bg_side_his`：`#74CF79/#56AD5B` → `#469753/#377C42`（压得最多）
- **文字清晰**：功能卡标题加 `setShadowLayer(6f,0,2,0x99000000)` 投影；副标题由偏灰的 `0xFFC9D6EC` 改为更亮的 `0xFFE7EEFA` 并同款投影，亮底/压暗底上都看得清。

## 4. 选中卡片底层阴影去除（图4）
- `bindFocus` 与 `MainActivity.switch()` 里的选中状态去掉 `elevation` 阴影（`v.elevation = 0f`）。深色底上 elevation 投影发脏发糊、还拖累盒子 GPU，去掉后选中只靠 1.06 缩放 + 白描边浮层标识，干净利落。

## 5. 右侧推荐卡边框过大收紧（图5）
- `item_side_flat` 海报占比加大（`50x60` → `54x64`），左右内边距收紧（`paddingStart 8→6`、`paddingEnd 12→10`），卡间距 `8→6dp`，整列更紧凑，不再一圈大蓝框。

## 6. 遥控器切换动画优化
- 焦点缩放动画 `150ms` → `120ms`，并换 `DecelerateInterpolator(1.6f)` 减速插值，遥控器左右/上下切换更跟手、收尾不拖泥带水。
