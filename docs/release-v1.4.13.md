# AIStream TV v1.4.13

大哥投影实测三张选台面板截图点名：v1.4.12 的自绘跑马灯引入回归——短台名（CCTV1 这类）不该滚却滚了、面板节目单没跑完、单行台名滚过头把前面三位编号挡住、台名（标题）没跑完。

- **跑马灯根因修复（`MarqueeLabel`）**：上一版 `bind()` 用 `match_parent` 的 TextView 自身宽度当「可用宽」，RecyclerView 回收 / 快速滚动时这个宽度量不准（时大时小），导致溢出判定和行程全错。本版改为：**TextView 改 `wrap_content`（自身宽度 = 文字宽，判定不再依赖布局宽度）**，**可用宽一律取自外层裁剪壳（box）宽度**（布局完成后量，稳定），文字宽用 `paint` 直量；仅当「文字宽确实 > 可用宽」才注册跑马灯——短台名绝不滚、行程算得准。
- **单行台名不再挡编号**：行程用壳宽计算，文字向左平移时由外层 `FrameLayout(clipChildren=true)` 在壳左缘裁剪，绝不越过壳去压住前面的三位编号方块。
- **台名 / 面板节目单都跑得完**：行程 = 文字真实超出壳宽，末态整段完整可见，不再「跑一半就回开头」。
- **面板节目单整体下移**：节目单跑马灯块往下挪 6dp（大哥点名「还可以往下来一点」），和上方标题拉开间距。
- 版本号 1.4.13（versionCode 27）。
