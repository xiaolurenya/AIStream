# AIStream TV v1.4.9

大哥点名「登录界面美化重构 + 选中没有动画不知道选哪里」：

- **焦点反馈补齐（根因）**：登录页之前只给控件设了 `focusable`，**从没调过 `bindFocus`**——遥控器上下移动既没放大、没白描边、也没提示音，完全看不出选中谁。现在协议 chips / 地址 / 端口 / 用户名 / 密码 / 进入 / 清除 全部统一 bindFocus：放大 1.06 + 白描边浮层 + 轻提示音，和首页同一套手感。
- **界面重构**：输入框墙改成**居中大卡片**——品牌色竖条 + 「AIStream TV」大标题 + 版本号药丸的品牌头；输入框换新底色（比卡片暗一档 + 细描边圆角），高度统一 54dp；错误提示从裸文本升级成**金色药丸条**（半透明金底 + 描边 + 150ms 淡入）；「进 入」按钮加大；表单自动初始焦点（新配置落在地址格，开机直接往下填）。
- **输入更顺**：地址/端口/用户名回车自动跳下一格（imeOptions actionNext），密码格 actionDone。
- 版本号 1.4.9（versionCode 23）。
