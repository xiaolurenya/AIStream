# AIStream TV v1.4.8

大哥投影实拍两图点名的 IPTV 一批问题：

- **首页直播小窗投影上左右大片无画面**（图1）：小窗比例从 FIT 改 **ZOOM 等比铺满**——投影/电视上 hero 容器普遍比 16:9 宽，FIT 会在左右留两条黑边/暗底；铺满后画面永远填满整个小窗（跟 v1.4.6 全屏播放器同一口径）。
- **出小窗后视频叠在栏目行上、又丑又卡**（图2）：根因是 PlayerView 默认用 **SurfaceView**，一批盒子/投影上 surface 位置不跟着布局走，预览一开画面「钉」在原地，栏目行从它上面滚过去叠成鬼影。小窗改 **TextureView**（普通 View，跟布局/缩放/滚动走）；同时预览开着时**暂停右侧推荐列轮播**（视频解码 + 换图解码同时跑把弱性能盒子拖卡）。
- **按返回直接退应用**：预览小窗开着时，第一下返回**先收小窗**（焦点给「首页」卡，不能给直播卡——它一聚焦小窗又弹回来），再按才退出。
- **选台界面「✕ 关闭」按钮选不到**：三个元凶一起修——左侧分组列的 **ScrollView 默认自己可聚焦且无视觉反馈**，D-pad 导航时隐形截胡（禁掉它的焦点，目标留给分组文字）；关闭按钮**补 bindFocus** 放大描边反馈；搜索框 UP/DOWN 明确指到「关闭按钮/频道列表」，导航路径不再被搅混。
- **节目单不出全**：选台面板底部「正在播/接下来」和首页小窗的节目行从 1 行放开到 **2 行**，长节目名不再截断。
- **选台交互卡顿**：搜索框每敲一个字就 new 一个 ChannelAdapter 全量重建列表（+ item 动画）——改成**复用同一个 adapter 只换数据**，选台列表去掉 item 动画（遥控器一按立刻换高亮）；顺手修了「面板打开滚动定位在筛选状态下滚错行」的隐藏 bug。
- 版本号 1.4.8（versionCode 22）。
