# AIStream TV v1.4.10

大哥点名「IPTV 选台界面字体有点大、顶部拥挤、内容看不到，节目单在底部被截断显示不全」：

- **选台面板顶部压缩**：原面板标题 20sp + 一行操作提示 + 关闭钮三层叠在顶部，投影上一挤内容都看不清。现在标题压成单行 16sp，删掉「上下选台…」提示行（操作自己会），关闭钮从 36dp/13sp 缩到 30dp/12sp。
- **节目单换位置（核心）**：原来「正在播 / 接下来」钉在面板最底部，台名后面的节目名经常被截断看不见。现**挪到标题正下方**，一眼就是「当前台 + 正在播」，不再被裁。
- **选台行整体收紧**：行高 62dp → 54dp，三位编号块 36×32 → 30×26、字号 14sp → 12sp，台名 15sp → 13sp，节目小字 12sp → 11sp，内边距与间距收窄；台标三档 `ch_logo_w/h` 同步下调（默认 40/28 → 36/26，sw600dp 44/28 → 40/28，sw900dp 44/30 → 42/30）。一行能多露好几台，选台列表更密更全。
- **搜索框微调**：高度 42dp → 40dp、字号 14sp → 13sp。
- 版本号 1.4.10（versionCode 24）。
