# AIStream TV v1.4.16

大哥投影实拍 4 图点名，聚焦「选台行更清爽 + 跑马灯循环滚动 + 右侧推荐卡描边归位」。全在 `native-tv/`，手机零改动、8890 正式版不动。

## 1. 选台行标题字号过大 + 选中边框过大左右显示不全（图1/图2）
- **标题字号**：`item_channel` 台名 13sp → **12sp**（节目名 11sp 不动），一行更清爽。
- **选中边框过大**：整行是通栏宽条，原来焦点放大 1.06 + 3dp 描边，投影上白框上下撑出一大截、放大后左右超出面板被裁（「左右都不全」）。三刀一起收：
  - `bindFocus` 加 `scale` 参数（默认仍 1.06，海报网格不变），**选台行改 1.02** —— 只提一点动感，选中标识主要靠描边；
  - 描边 **3dp → 2dp**；
  - `rvCh` 加 `clipChildren="false"`，放大后的描边完整画出不被列表裁掉（顶部裁剪 `clipToPadding` 保持默认 true，v1.4.12 修的「快速下翻顶住搜索框」不回归）。

## 2. 跑马灯改「一直循环滚动」，不再回弹（图2）
- **大哥点名**：滚完滚回开头（回弹）不对，要的是像新闻条一样一直循环。
- **无缝循环的经典实现**：一轮行程 = 文字实宽 + 48dp 段间空隙，offset 在 `[0, 行程)` 内用 `%` 无限转圈；onDraw **同时画两份文字** —— 第一份正在退出左边，第二份贴着空隙从右边跟进，相位归零瞬间第二份恰好接到第一份的位置，**视觉完全无缝：永远有字在滚、没有空窗、没有回弹**。
- 首次绑定仍停 1.2s 让人读一遍开头，之后无限循环不再停顿；~30fps 重绘节流保留；自绘裁剪（不遮编号/台标）不变。

## 3. 右侧 5 张海报卡焦点边框位置不对（图3）
- **根因一**：焦点描边圆角 12dp vs 卡片 `bg_card` 圆角 10dp —— 四角比卡片更圆，描边角**悬浮在卡片轮廓之外**，看着像框贴歪了。描边圆角改 10dp 与卡片对齐。
- **根因二**：`rvSide` 没有 `clipChildren=false`，焦点卡放大后描边超出列表边界被裁掉一块，看起来「位置不对」。补 `clipChildren="false"`（其父级 hero 行与页面根都已是 false）。

## 4. 焦点放大过界 → 缩小一点、居中（图4）
- 右侧推荐卡贴屏幕右缘，1.06 放大后描边直接出屏。**放大收到 1.03**，配合上面的裁剪豁免，描边完整且不再过界。
