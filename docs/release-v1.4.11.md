# AIStream TV v1.4.11

大哥发选台面板实拍点名：「没有台标的文字没有靠左。同时修复所有频道文字从右往左移动，这样就能避免有些频道名称过长不显示问题」：

- **无台标频道文字靠左（根因）**：选台行里台标容器（`FrameLayout`）原来**永远占着位**，没台标的频道只是把图清空，左边仍空出一截，台名被顶到中间。现在给台标容器加 id（`flLogo`），频道没台标时**整个容器 GONE**，台名紧跟编号真正靠左；有台标的照常显示。
- **频道文字跑马灯（核心）**：台名和「▶ 正在播」节目名从 `ellipsize="end"`（超长截断「…」）改成**跑马灯**（`singleLine + ellipsize=marquee + marquee_forever`），并在绑定行时 `isSelected=true`——**所有频道行的长文字都会从右往左循环滚动**，频道名再长也能看完，不再截断；短文字不滚、维持原样。
- **面板节目单同步跑马灯**：选台面板标题下的「正在播：xxx（至 HH:mm）/ 接下来 xxx」同样改跑马灯（面板窄更容易截），无节目单时不滚。
- 版本号 1.4.11（versionCode 25）。
