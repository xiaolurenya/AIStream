# AIStream TV v1.4.22

大哥打回 v1.4.21（截图）：海报清晰是清晰了，但「只有半边」——右边一张海报，左边一大块空的黑。要求换思路，不许再留半边空。

## 修法：hero 按图自适应 + 环境色补底

**竖版海报（绝大多数情况）**
- 海报照旧右侧原比例完整清晰展示（v1.4.21 的成果保留）。
- **左边空档不再死黑**：加载成功后从海报左缘取平均色，在 hero 底层铺一条「海报边缘色 → 页面底色(#112A5C)」的横向渐变——海报像「融」进底色一样，整幅 hero 都是画面的一部分。
- 这是**取色补底**（Apple TV ambient 思路），不是模糊：没有第二张被糊掉的图，被点名过的「右清左糊」不会回来。
- 白底海报边缘过亮会自动压暗 30%，hero 不发白发亮；文字区仍由原有左侧压字渐变兜底。

**横版图（万一源给的是剧照/横版封面）**
- 之前 `fitCenter` + 右锚定遇到横版图会宽超容器被裁成半张——这正是「万一只有半边的」隐患。
- 现在按加载到的位图宽高自动选路：横版直接整幅铺满 hero（清晰原图 centerCrop）+ 左侧压字渐变，就是标准的影视首页横幅。

**其他**
- 图片加载失败：补底层和海报都收起，退回页面底色，不残留上一张的底。
- 直播预览小窗收起时按当前形态恢复（横版态不会把海报又叠出来）。
- v1.4.20 的服务端 `pic.large` 优先保持不变（清晰度根）。
