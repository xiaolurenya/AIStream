# AIStream TV v1.4.6

大哥逐图点名的七处体验修复：

- **IPTV 选台面板收窄**：大电视档 380→320、平板档 340→300、手机档 300→264，并提高了面板不透明度；打开面板时自动藏掉顶部台名，消除「台名透出来跟面板叠字」的重叠。选台行高 64→58、编号方块同步缩小，小面板里更透气。
- **IPTV 搜索框遥控器可达**：之前左右键在面板里一律收面板，导致搜索框/分类条选不中。现在只有焦点在「频道列表 / 关闭按钮」时左右键才收面板，搜索框和分类条正常导航；返回键一律优先收面板（不再误退出直播）；搜索框加了焦点描边，一眼看得见选没选中。
- **播放器默认真全屏**：`filled` 默认改为 true，铺满改用 `RESIZE_MODE_ZOOM` 等比裁切（之前用 FILL 会把画面拉变形），上下不再露出背后的海报底图；按钮给出「适应」/「全屏」切换。
- **「显示更多」提速**：进分类页就预取下一页，点开基本秒出；去掉了进出页面的转场动画（之前弹出满屏要等动画，显得迟钝）；焦点跳转延时 120→80ms。
- **海报卡再缩一档**：默认 96×136、平板 104×150、大电视 114×166，标题字号同步下调，右边栏目更紧凑。
- **栏目标题可弹满屏**：首页每个栏目的标题现在可聚焦 + 白描边，确认键 / 点击直接弹出该栏目的满屏海报墙（按下返回自动归位），对应顶部分类标签同一个入口。
- 版本号 1.4.6（versionCode 20）。
