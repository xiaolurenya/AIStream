# AIStream TV v1.4.18

大哥投影实拍点名：果果1 分组这种超长节目标题（「花容失色：取花点 第0…」）被省略号截断，要**自动监测到超长就滚动显示**。

## 台名超长才滚（自动监测）
- v1.4.17 把台名一刀切成全静态（当时点名「频道也在滚动」），但果果1 这类**频道名本身就是节目名**（超长），静态只能出省略号，尾部的集数永远看不见。
- v1.4.18 改回 **`MarqueeTextView` 按宽度自动判定**：文字实宽 > 名字区宽才注册循环滚动（无缝循环，v1.4.16 行为），**CCTV1 这类短名一帧不动**——超长滚、短名静，两边都满足。
- 台标加载回调里的 `name.remeasure()` 一并恢复（v1.4.14 定式）：台标异步加载挤压名字区时行程自动跟上。
- `ellipsize=end` 保留作兜底：只对没超宽的静态行生效（超宽的行走自绘循环，不出省略号）。
